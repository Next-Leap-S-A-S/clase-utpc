# El derecho ya cambió, ¿y los abogados?

Página de clase de Next Leap para la UTPC (2 horas, posgrado y abogados en ejercicio). Cinco pestañas: El cambio, Método RCI, Laboratorio (4 ejercicios, 10 prompts), Asistentes (3 recetas) y Antes de servir.

Se edita en `src/` y se genera con `python3 src/build.py`, que produce `index.html` autocontenido y revisa la prosa. Derivada de `asistentes-ia-sabana`. Sin publicar todavía.
